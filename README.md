# The Change Calculator
A final project for my scripting class.

# Objective and Problem
The client has asked for a program that will display a welcome message then randomly generate a purchase total from $0.01 to $20.00. The program will calculate how much change to give the customer based on USD currency of 1, 5, 10 dollar bills and quarters, nickels, dimes, and pennies. The program will then ask if the user would like to restart the program or end it, then display a goodbye message.

# Concepts Demonstrated
This program uses Python's decimal and random modules. Concepts demonstrated are code commenting, data validation and error handling, modular programming, decimal precision handling.
